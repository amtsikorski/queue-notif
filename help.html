Queue Monitor help

Set up Discord notifications for your queue position in a couple of minutes.

Get your Discord webhook URL

1

Pick a server and channel

Choose the server you want the bot to post in (you'll need admin permissions there), and the channel it should send updates to. Either can be new or one you already use.

2

Create the webhook

Open the server settings.

Click Integrations in the sidebar, then Webhooks.

Click New Webhook, then set its name and channel. Giving it its own channel makes it easy to mute everything except @mentions.

3

Copy the Webhook URL into the extension

Click Copy Webhook URL and paste it into the Webhook URL field in the Queue Monitor popup.

Get your Discord user ID

1

Turn on developer mode

Open Discord settings.

Click Advanced in the sidebar, then turn on Developer Mode.

2

Copy your user ID into the extension

Open your user profile, click Copy User ID, and paste it into the User ID field in the Queue Monitor popup.

General tips

Inactivity warnings

If the ticketing page warns that you've been inactive too long, keep that tab active (last clicked) rather than switching away while you wait.

Notification volume

Set the bot's channel to notify only on @mentions, so you only hear from it when your position crosses the threshold.
